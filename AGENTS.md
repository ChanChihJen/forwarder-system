# Repository boundary

This repository is the public discussion, requirements, and wireframe repository for the forwarder system.

- Do not implement, commit, or push the Laravel MVP from this repository.
- Do not add customer-derived operational data, credentials, generated HBL/PDF files, or backend deployment artifacts to this public repository.
- The canonical MVP source is the private GitHub repository `ChanChihJen/forwarder-system-mvp`.
- Its local checkout is `/Users/chanchihjen/Documents/CodexProject/forwarder-system-mvp`.
- When a task changes the MVP application, switch to that checkout before inspecting or editing code. Do not use any legacy local `src/` directory here as the development source.
- Changes to discussion documents, process references, and static wireframes remain in this public repository.

If a request spans both repositories, keep public documentation changes here and application changes in the private MVP repository as separate commits.
